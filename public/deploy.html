Deploy the contract

One-time setup. This sends a single transaction from your own wallet to create the gap133 pay-per-query contract on Arc mainnet. Gas is a few cents of USDC.

  1. The attester address is read from this deployment's /api/info, so SERVICE_SECRET must already be set in Vercel.
  2. The price is fixed at 0.01 USDC per query (you can change it later with setPrice).
  3. After it confirms, copy the contract address into Vercel as CONTRACT_ADDRESS and redeploy.
