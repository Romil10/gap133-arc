How it works

contractloading…

The service answers your first request with HTTP 402 Payment Required and a one-time nonce. You call pay(nonce) on the contract with the exact price in native USDC. The service reads the payment on Arc (finality is under a second) and returns the data with the attester's signature in the X-Signature header. The attester address is stored in the contract, so anyone can check it.

curl -i https://YOUR-DEPLOYMENT/api/query?kind=top
# -> 402 { nonce, challenge, contract, price }
# pay(nonce) on Arc, then:
curl https://YOUR-DEPLOYMENT/api/query?kind=top \
  -H "X-Payment-Challenge: <challenge>" -H "X-Payment-Tx: <tx hash>"

Agents: see examples/agent.mjs for a script that pays and verifies on its own.
